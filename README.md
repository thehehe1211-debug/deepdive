# Into the Deep - Pixel Ocean !!

A scrolling webpage that takes you from the sunlit surface of the ocean down to the bottom .there are also many pixletaed animals, lesgo !!

**Try it now!!** https://thehehe1211-debug.github.io/deepdive/

## Features

Five ocean zones: Sunlight, Twilight, Midnight, Abyssal and Hadal, from 0 to 10900 m
small descrip for each stage
A pixel art sea creature in every zone
The background gets darker as you scroll down
A gently bobbing animation on the creatures, turned off for visitors who prefer reduced motion
Works on phones and desktops

## Why I made this

Because I love everything about aquatic live , I wanted to make something related to it

Built with plain HTML and CSS only

## Run locally

1. Clone the repo

   ```
   git clone https://github.com/thehehe1211-debug/deepdive
   ```

2. Go to the project folder

   ```
   cd deepdive
   ```

3. Install the Live Server extension

4. Right-click `index.html` and choose **Open with Live Server**
