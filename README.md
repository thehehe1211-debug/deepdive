# Into the Deep — Pixel Ocean

A scrolling webpage that takes you from the sunlit surface of the ocean down to the bottom of the Mariana Trench, meeting pixel-art sea creatures in every depth zone along the way.

**Try it now:** https://thehehe1211-debug.github.io/deepdive/

<img width="1507" height="702" alt="image" src="https://github.com/user-attachments/assets/a84b901f-f139-4415-8577-80fe717a3127" />


## Features

- Five ocean zones: Sunlight, Twilight, Midnight, Abyssal and Hadal, from 0 to 10,900 metres
- Depth range, a short description and a fun fact for each zone
- A pixel-art sea creature in every zone, including a turtle, manta ray, octopus, glowing deep-sea fish, pufferfish and hermit crab
- The background gets darker as you scroll down
- A gently bobbing animation on the creatures, turned off for visitors who prefer reduced motion
- Works on phones and desktops

## Why I made this

Because the deep ocean is one of the least explored places on Earth, and I wanted to show how the light fades and the life changes the further down you go.

## How I made this

Built with plain HTML and CSS, using the Press Start 2P font from Google Fonts for the pixel look. No JavaScript.

## Run locally

1. Clone the repo

   ```
   git clone https://github.com/thehehe1211-debug/deepdive
   ```

2. Go into the project folder

   ```
   cd deepdive
   ```

3. Install the Live Server extension (VS Code)

4. Right-click `index.html` and choose **Open with Live Server**
